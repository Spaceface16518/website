# Editorial / A practice in making

Purpose: Present engineering as a thoughtful creative practice. Project narratives are the focus, followed by personal context, professional history, and contact.

Visual direction: An oversized serif cover line, restrained sans-serif metadata, warm paper, terracotta, and muted sage. The PowerPercept feature uses an original abstract SVG pressure-field illustration; this is explicitly labeled as a concept illustration, not a product screenshot or measured dataset. Numbered project studies borrow the rhythm of an independent design magazine.

Structure: Cover → featured project → project studies → about → experience → contact. No blog. Responsive grid collapses into a linear reading order. System fonts require no third-party requests. All content is rendered from shared profile data where possible. Native anchors, skip link, visible focus, semantic headings, and reduced-motion support.
