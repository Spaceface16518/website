# The open notebook

A chronological personal portfolio for Amrit Rathie. Warm paper, copper annotations, large serif headings, and a continuous timeline give work a narrative: recent independent projects lead back through community, research, and professional experience.

The purpose is discovery through career context rather than a conventional project gallery. Recent projects are shown together as a richly annotated chapter; older work has individual timeline entries. A personal section and direct contact close the story. No blog or invented employment, graduation, or project dates.

Built as static Astro with no client JavaScript, external fonts, or image requests. Uses the shared source-backed profile data. Mobile collapses to a single continuous timeline; desktop uses an explicit date rail. Includes semantic sections, skip navigation, visible keyboard focus, descriptive link labels, and reduced-motion support.
