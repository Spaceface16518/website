# Workspace

A technical collaborator's view into Amrit's work. A charcoal and acid-yellow workbench gives projects the primary navigation, paired with a personable introduction and clearly sourced experience.

The eight-item project explorer changes the visible overview without a page reload. Each choice is a real anchor, keyboard operable, with an active state announced via aria-current. Without JavaScript all project articles remain available. URL hashes preserve individual project entry points. Navigation, resume, external project links and email work without JavaScript.

System fonts, CSS-drawn abstract artwork, responsive two-column project navigation on mobile, reduced motion support, visible keyboard outlines and a skip link avoid external asset dependencies. Content comes from the shared sourced profile and public resume. No blog or unsupported employer/graduation claims.

Purpose: invite technical collaborators to explore projects across disciplines, with enough personal and career context to begin a conversation.
